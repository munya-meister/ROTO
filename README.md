# Rise of the Overlooked (ROTO)

A Zimbabwe-first talent discovery and empowerment platform.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## MVP scope

- Cinematic responsive homepage with animated 3D-inspired elements
- Mission, illustrative talent categories, family stories, discovery process
- Nomination form **preview only** — does not transmit or persist information
- No fabricated talent profiles, impact figures or testimonials

## Next phase

- Supabase authentication, role-based dashboards and secure media storage
- Nomination API with abuse protection, privacy controls and staff review
- Verified talent profiles, explicit media consent and private welfare check-ins
- Investor verification, introductions and clear agreements before funding
